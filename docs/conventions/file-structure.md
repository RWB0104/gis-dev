# General (non-component) TypeScript File Structure

For plain `.ts` files (utils, services, etc. — not components), no folder-per-file or `index.ts` is required:

```
FileName.ts
FileName.spec.ts
```

A file may or may not sit inside a grouping folder — both flat and grouped placement are valid, unlike organism/template/page (see `./components.md`) which always require one.
